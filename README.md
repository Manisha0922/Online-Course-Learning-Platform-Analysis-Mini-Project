# Online Course and Learning Platform Analysis

## Project Overview
This project analyses online course data to understand course categories, student enrolments, ratings, and pricing patterns.

## Objectives
- Analyse online course data.
- Identify popular course categories.
- Find courses with high student enrolment.
- Compare course ratings across platforms.
- Explore the relationship between course price and rating.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- GitHub

## Project Workflow
1. Dataset collection
2. Data loading and exploration
3. Data cleaning
4. Exploratory Data Analysis (EDA)
5. Data visualisation
6. Findings and conclusion

## Project File
- `Online_Course_Learning_Analysis.ipynb` — Contains the Python code, analysis, and visualisations.

## How to Run
1. Open the notebook using Google Colab.
2. Upload the required CSV dataset if it is stored separately.
3. Run the notebook cells in order.

## Expected Outcomes
The analysis helps understand course popularity, enrolment patterns, ratings, and pricing trends.
